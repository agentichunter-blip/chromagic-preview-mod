# System picker logos

Nintendo wordmarks from Wikimedia Commons, used side by side to identify the GB/GBC system choices:
- [Game Boy](https://commons.wikimedia.org/wiki/File:Nintendo_Game_Boy_Logo.svg)
- [Game Boy Color](https://commons.wikimedia.org/wiki/File:Game_Boy_Color_logo.svg)

Both source pages designate the simple text logos PD-textlogo; Nintendo retains its trademarks. Original SVGs are included. `generate.py` uses CairoSVG and Pillow to generate the checked-in 60×68 RGB565 images in the header. The firmware needs no SVG renderer, extra SD files, or artwork reads for folders.
