# Upstream MiSTer releases

Historical prebuilt MiSTer `.rbf` binaries are omitted from this source fork. They are not Chromatic FPGA `.fs` images and are not used by this MCU mod or the Chromatic FPGA build.

The MiSTer source and its notices remain in the parent directory. Historical releases are available from the upstream Gameboy_MiSTer repository named in the root NOTICE.
